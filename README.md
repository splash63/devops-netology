# devops-netology
Для игнорирования файлов по маскам:
Соответствует любому файлу, оканчивающемуся на .tfstate
Соответствует любому файлу, который содержит .tfstate. и имеет что-то после него
Соответствует только файлу с точным именем crash.log
соответствует файлам вида crash.<что угодно>.log
соответствует любому файлу с расширением .tfvars
соответствует любому файлу с расширением .tfvars.json
Соответствует только файлу override.tf
Соответствует только файлу override.tf.json
Соответствует любому файлу, который заканчивается на _override.tf
Соответствует любому файлу, который заканчивается на _override.tf.json
соответствует любому файлу с расширением .terraform.tfstate.lock.info
